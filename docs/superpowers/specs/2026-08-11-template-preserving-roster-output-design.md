# 原样复制值班表模板输出设计

## 目标

未来三天的每一份值班表必须沿用现有实际值班表的完整格式。系统不得重新绘制表格；应复制一份完整模板，只修改日期、排班人员和与当天人员状态直接相关的备注，然后按日期另存到输出批次目录。

## 标准模板

- 默认模板为 `输入/过往三天/` 中业务日期最新且结构完整的实际值班表。
- 当前工作区使用 `输入/过往三天/8.13值班表.xls` 作为标准模板。
- 模板主表为 `8月排班表`，其他 sheet 必须原样保留。
- 若最新文件的主表缺行、打印区域异常或结构指纹与完整历史表明显不同，应跳过该文件并选择业务日期次新的完整模板，同时在运行摘要中记录原因。
- 当前 `8.11值班表.xls` 的主表存在 `A1:H2` 打印区域异常，不能作为标准模板。

## 技术方案

采用 Microsoft Excel COM 自动化完成复制和修改：

1. 以只读方式打开标准模板。
2. 使用 Excel 原生 `SaveCopyAs` 复制为目标日期文件。
3. 打开副本，仅修改允许变更的单元格值。
4. 使用原始 `.xls` 格式保存并关闭。
5. 不通过 `openpyxl`、`xlwt` 或重新创建工作簿的方式生成正式日表。

该方案要求 Windows 安装 Microsoft Excel。解析、求解和不可行报告仍由现有本地 Python 流水线负责。

## 允许修改的内容

- 主表标题中的日期和星期。
- 各岗位、时段对应单元格中的人员姓名及必要的岗位说明。
- 当天请假、休假、调休和临时任务对应的备注文字。
- 目标副本的文件名。

禁止修改：

- sheet 名称、数量和顺序。
- 合并单元格、行高、列宽、隐藏行列。
- 字体、字号、颜色、边框、填充、对齐、换行和数字格式。
- 公式、图片、对象、页面方向、页边距、缩放和打印标题。
- 与目标日期无关的辅助 sheet 内容。

## 单元格映射

系统从标准模板和最近三份历史表中识别：

- 第一列岗位名称。
- 第一行日期和时段标题。
- 岗位行与时段列的交叉单元格。
- 底部“其他”备注区域。

映射按岗位文字和时段文字定位，不依赖固定行号。模板结构发生变化时必须停止，不得把人员写入猜测位置。

写入人员时沿用目标单元格原有格式。若一个单元格包含不同颜色或字号的富文本，系统应通过 Excel 原生字符格式复制相邻历史单元格的人员文本样式，不能整格重设格式。

## 输出规则

每次运行创建新的：

`输出/YYYYMMDD-HHMMSS/`

成功批次包含：

- `YYYY-MM-DD值班表.xls`，共三份。
- `排班说明与告警.xlsx`。
- `运行摘要.json`。

如果任一日表复制、修改、保存或校验失败，三份正式日表均不发布。临时文件放在批次内的隐藏暂存目录，三份全部通过后再一次性移动到批次根目录。

## 格式一致性校验

保存后使用 Excel 重新打开模板与输出文件，比较以下格式指纹：

- sheet 名称、数量和顺序。
- 主表使用区域、合并区域集合。
- 每行行高、每列列宽、隐藏状态。
- 每个单元格的字体、字号、粗体、斜体、颜色、填充、边框、对齐、换行和数字格式。
- 页面设置和打印区域。
- 公式及非允许修改单元格的值。

允许差异只能出现在日期、人员和当天备注的白名单单元格中。任何其他差异都视为失败。

每份日表还必须由 Excel 导出为预览并进行视觉检查，确认无截断、错位、打印区域异常或格式漂移。

## 业务校验

正式发布前同时验证：

- 文件日期与表内日期一致。
- 所有人员都来自当前最新人员表。
- 请假或不可用人员未出现在冲突时段。
- 同一人员没有出现在重叠岗位。
- 必需岗位没有空缺。
- 三天排班满足最近三天岗位轮换和负荷均衡规则。
- 半日请假在备注中保留准确时段。

## 错误处理

以下情况停止正式输出：

- 未安装或无法启动 Microsoft Excel。
- 找不到结构完整的模板。
- 模板岗位或时段无法唯一映射。
- 保存后格式指纹不一致。
- Excel 导出预览失败。
- 任何排班硬约束无法满足。

阻断批次只生成运行摘要和告警报告，并固定提供三套方案，列出优点、缺点、沟通对象和建议说法。

## 低 Token 原则

- Excel 结构识别、复制、修改和格式比较全部由本地脚本执行。
- 对话只读取 `运行摘要.json`，不读取完整单元格或格式明细。
- 格式指纹保存为本地 JSON，仅在校验失败时读取差异摘要。
- 模板未变化时可复用已验证的单元格映射；文件大小、修改时间和内容哈希任一变化时重新识别。

## 验收标准

- 输出文件与标准模板的非白名单格式指纹完全一致。
- 将模板和输出截图并排查看时，除日期、人员和当天备注外无可见差异。
- 三天分别输出三个 `.xls`，文件名与表内日期一致。
- 修改输入人员、历史表或变更文本后重新运行，不覆盖旧批次。
- 不可行或模板异常时不生成可被误用的正式日表。
- 自动测试覆盖模板选择、映射、白名单修改、格式指纹、部分失败回滚和真实 Excel 集成流程。
